# ServerUI v0.1.0

Primera versión de ServerUI: fundación y demo TUI de Stage 0. Funciona con datos
simulados y no consulta métricas reales ni modifica el host.

- Workspace Rust modular: núcleo, proveedores, TUI y binario separados.
- MockProvider determinista con escenarios normal, vacío y error recuperable.
- Dashboard simulado, navegación y pantallas provisionales de Procesos,
  Servicios y Ajustes.
- Ayuda, resize, refresco configurable, ASCII y ausencia de color.
- Restauración del terminal tras salida, errores y pánico con unwinding.
- Tests Linux/Windows, validación PTY y sesiones SSH dentro de Ubuntu 24.04.

Descarga el archivo de tu plataforma, extrae su contenido y ejecuta:

```sh
./serverui --demo
```

En PowerShell: `./serverui.exe --demo`. Para terminales limitados añade
`--ascii --no-color`. Pulsa `?` para ayuda y `q` o Ctrl+C para salir.

Se adjuntan binarios x86_64 para Linux GNU y Windows MSVC, construidos por CI
desde el commit publicado, junto con sus checksums SHA-256 y `SHA256SUMS`.
El código fuente también está disponible en los archivos automáticos de GitHub.

En una medición local Linux de diez minutos, el release mantuvo 2,69 MB de RSS
y consumió 0,0383 % de un núcleo de CPU en reposo. Son resultados de ese entorno,
no garantías para todos los equipos o conexiones SSH. La evidencia completa y
las limitaciones están en `docs/ACCEPTANCE_STAGE_0.md`.

Limitaciones: sin proveedor Linux real, procesos reales, systemd, APT,
contenedores administrables ni acciones privilegiadas. La prueba SSH se ejecutó
en un contenedor Ubuntu aislado; no equivale a una VM Ubuntu Server completa.
