# ServerUI v0.2.0

Stage 1 incorpora Dashboard y procesos Linux reales de solo lectura. Ejecutar
como usuario normal, sin sudo; no modifica el sistema ni realiza acciones
administrativas.

- CPU, RAM, swap, uptime y espacio disponible por montaje.
- Procesos visibles con filtro por nombre/PID, orden por CPU/RAM/PID/nombre,
  selección estable, desplazamiento y detalles.
- CPU inicial pendiente hasta contar con baseline válido; porcentaje de proceso
  por núcleo. Identidad PID + inicio para tratar desaparición/reutilización.
- Recolección fuera del hilo de UI, canales acotados y lector de teclado sin
  sondeo activo. Se conserva demo determinista y multiplataforma.
- Binario GNU con baseline Ubuntu 22.04/glibc 2.35, comprobado mediante readelf.
- Checksum corregido: LF explícito evita que sha256sum interprete CR como parte
  del nombre al generar paquetes desde Windows.

Linux x86_64, después de extraer el paquete:

```sh
./serverui --ascii --no-color
```

Modo demo en Linux: `./serverui --demo`. Windows x86_64:
`./serverui.exe --demo`. Pulsa 2 para Procesos, / para filtrar, s para ordenar,
Enter para inspeccionar y q o Ctrl+C para salir. Dentro del filtro q es texto;
Ctrl+C siempre permite salir. Se requiere una terminal interactiva.

Se adjuntan archivos Linux GNU y Windows MSVC construidos por CI desde el commit
publicado, checksums individuales y SHA256SUMS con saltos LF. Verificar el
checksum antes de instalar. La guía de Ubuntu está en docs/INSTALL_UBUNTU.md.

Validación: 35 tests Rust en Windows y 39 en Linux, más regresión de empaquetado,
Clippy, release, nueve casos PTY y SSH en Ubuntu 22.04 y 24.04. El usuario confirmó
funcionamiento general en una laptop Ubuntu Server 22.04.5 x86_64 por SSH.
Una medición local previa de 120 s mantuvo 2,99 MB de RSS y 0,20 % de un núcleo;
no representa una garantía ni una medición de la laptop física.

Limitaciones: sin señales a procesos, systemd, APT, administración de red/discos
ni funciones de Stage 2. Solo se muestran procesos/montajes visibles; permisos,
namespaces y cgroups condicionan los datos. Windows dispone únicamente de demo.
