# ServerUI v0.4.0

Stage 3 añade gestión de paquetes APT en Ubuntu. Abre **Paquetes** con `5`
para ver herramientas recomendadas que figuran en los índices locales. Pulsa
`/` para buscar por nombre. Una búsqueda vacía vuelve a las recomendaciones.

- `i` propone instalar, `u` actualizar el paquete seleccionado a su versión
  candidata y `d` eliminarlo conservando su configuración.
- Revisa la simulación y pulsa `y` para autorizar el intento o `n/Esc` para
  cancelar. La operación muestra progreso y las últimas líneas de salida.
- Tras una instalación nueva de un solo paquete, `b` prepara una simulación de
  eliminación. La reversión de efectos de scripts o de versiones requiere
  recuperación específica.

Ejecuta ServerUI como usuario normal. En Ubuntu, aplicar usa `pkexec` con
autorización de polkit ya configurada. En SSH puede hacer falta un agente
en otra terminal. Windows y Linux incluyen modo demo con datos simulados.
Desde una terminal interactiva, ejecuta `./serverui --demo` en Linux o
`./serverui.exe --demo` en Windows; después pulsa `5`.

Las pruebas locales de Stage 3 incluyen 52 tests Rust en Windows y 62 en
Ubuntu, PTY, SSH, consultas APT y un ciclo de instalación, actualización y
eliminación con APT y dpkg reales en un contenedor. El fixture simuló la
concesión y denegación en la frontera de `pkexec`. La autorización de polkit
real por SSH queda pendiente de verificación.

Hay archivos para Linux x86_64 GNU con baseline Ubuntu 22.04/glibc 2.35 y
Windows x86_64 MSVC, con checksums SHA-256. Verifica el checksum del archivo
descargado y consulta la
[guía de instalación](https://github.com/Charmandiox9/ServerUI/blob/v0.4.0/docs/INSTALL_UBUNTU.md)
y la
[evidencia de aceptación](https://github.com/Charmandiox9/ServerUI/blob/v0.4.0/docs/ACCEPTANCE_STAGE_3.md).
