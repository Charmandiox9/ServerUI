# ServerUI v0.5.0

Stage 4 añade **Contenedores** y **Red y discos** a la interfaz de terminal.

- Pulsa `6` para listar contenedores y `e` para cambiar entre Docker y Podman
  locales. Enter muestra logs. `a`, `d` y `R` proponen iniciar, detener o
  reiniciar. Revisa el motor y el ID completo. Confirma con `y` o cancela
  con `n/Esc`.
- Pulsa `7` para consultar interfaces y direcciones IP (`n`), dispositivos de
  bloque (`b`) y montajes con capacidad (`m`). El inventario es de solo lectura.
- Prueba ambas vistas con `./serverui --demo` en Linux o
  `./serverui.exe --demo` en Windows. Para Docker real, ServerUI usa el socket
  local `/var/run/docker.sock` y los permisos actuales de tu cuenta. Podman usa
  su almacenamiento local.

Pasaron 55 pruebas Rust en Windows y 67 en Ubuntu. Se comprobó el inventario
con datos reales de Ubuntu y el listado de Docker en la laptop del usuario
por SSH. Las pruebas de inicio, detención, reinicio, cancelación y logs
utilizaron clientes simulados en un contenedor aislado. La validación del
ciclo completo con Docker y Podman reales queda pendiente.

Los paquetes x86_64 están disponibles para Linux GNU con baseline Ubuntu 22.04
y glibc 2.35, y para Windows MSVC. Verifica el archivo descargado con el
manifiesto SHA-256. [Guía de instalación](https://github.com/Charmandiox9/ServerUI/blob/v0.5.0/docs/INSTALL_UBUNTU.md) ·
